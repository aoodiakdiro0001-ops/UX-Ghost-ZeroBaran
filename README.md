## 📜 ما هو "UX-Ghost ZeroBaran"؟

نظام ذكي متكامل ومستقل لتتبع نقرات الزوار، تحركات الماوس، مسارات التصفح (Funnel Bottlenecks)، واكتشاف نقاط نقر العجز (Rage Clicks) ومشاكل تجربة المستخدم تلقائياً. يقوم بجمع بيانات التفاعل في موقعك بصمت، تحليل السلوك الجماعي للعملاء، توليد تقارير حرارية، واستخراج الثغرات التصميمية التي تمنع العميل من إكمال الشراء — دون دفع دولار واحد لأي أداة تحليل سلوكي مدفوعة، وبموارد مجانية بالكامل.

## 🛠️ الموارد المجانية البحتة (The Free Tech Stack)

| المكون | التقنية المجانية | دورها |
| --- | --- | --- |
| محرك التشغيل والمتابعة المجدولة (Cron) | GitHub Actions | خادم مجاني لتجميع بيانات السلوك، حساب الإحصائيات، وتوليد تقارير الأداء دورياً. |
| محرك التتبع الخفيف (Lightweight Tracker) | Vanilla JavaScript (< 2KB) | كود خفيف جداً يُوضع في موقعك لتسجيل الأحداث (Clicks, Scrolls, Form Drops) دون إبطاء الموقع. |

| قناة الواجهة والتنبيهات | Telegram Bot API + Streamlit Dashboard | إرسال تقارير المشاكل السلوكية الفورية وتوفير لوحة تحكم لعرض الخرائط الحرارية والتحليلات. |

## 🏗️ البنية البرمجية (Software Architecture)

يتكون النظام من 4 طبقات برمجية ذكية تتناغم لتعمل كمهندس تجربة مستخدم آلي:

```
[تفاعل الزائر مع الموقع (نقرات، التمرير، أو مغادرة الصفحة)]
                                  │
                                  ▼
[JavaScript Tracker Script  →  Supabase (تجميع بيانات السلوك)]
                                  │
                                  ▼
[Google Gemini / Groq API  →  اكتشاف الأنماط الفاشلة وتحليلها]
                                  │
                                  ▼
[تخزين التحليل في Supabase  ──►  تقرير الخلل السلوكي عبر تليجرام + لوحة Streamlit]
```

### تفصيل الطبقات

1. **طبقة الالتقاط والتتبع الخفيف** (`tracker/ux-ghost-tracker.js`)
   سكريبت جافاسكريبت مصغر يُضاف لموقعك. يسجل النقرات المتكررة في مكان واحد (Rage Clicks)، الحقول التي يهرب منها الزوار في الاستمارات، ونسبة التمرير في الصفحة دون أي تأثير على سرعة التحميل.

2. **العقل التحليلي لتجربة المستخدم** (`ai-core/ux_analyzer.py`)
   يقرأ مصفوفة تحركات الزوار، يحلل العوائق السلوكية، ويصدر توصيات تصميمية (مثال: *"الزر الفلاني يبدو كعنصر قابل للنقر لكنه ليس كذلك، مما يسبب إحباطاً لـ 35% من الزوار"*).

3. **طبقة الأرشيف والبيانات** (`supabase/schema.sql`)
   تحفظ بيانات الأحداث والمسارات مرتبة لتقديم مخططات الخرائط الحرارية ومعدلات الهروب لكل صفحة. مع سياسات RLS صارمة تحترم الخصوصية (GDPR).

4. **طبقة التوصيل والتنبيه الفوري** (`telegram_bot/`, `dashboard/app.py`)
   ترسل لك تنبيهاً فورياً عند رصد مشكلة سلوكية مفاجئة في موقعك، مع إمكانية فتح لوحة Streamlit لمشاهدة الخرائط الحرارية مجاناً.

## ⚙️ طريقة العمل خطوة بخطوة (End-to-End Workflow)

1. **الحدث**: يتصفح الزوار متجرك أو موقعك، ويقوم السكريبت الخفيف بتسجيل حركات التفاعل الأساسية (نقر، تمرير، مغادرة حقل نموذج، مغادرة الصفحة).
2. **المعالجة والتجميع**: يحلل معالج الأحداث `event_processor.py` البيانات التراكمية ويحسب المقاييس (نسبة التمرير، كثافة النقر، تسرب القمع).
3. **الاكتشاف والتوصية**: يدرس الذكاء الاصطناعي (Gemini أو Groq) أنماط نقرات الزوار ويكتشف السبب الذي يمنعهم من الوصول لصفحة الدفع.
4. **النتيجة الفورية**: يأتيك تقرير مفصل على هاتفك عبر تليجرام يحدد نقاط الضعف في تصميم موقعك وكيفية إصلاحها لرفع المبيعات.

## 🚀 التثبيت والبدء السريع

### المتطلبات
- حساب [Supabase](https://supabase.com) (مجاني تماماً)
- مفتاح [Google Gemini API](https://aistudio.google.com) (طبقة مجانية سخية)
- بوت [Telegram](https://t.me/BotFather) (مجاني)
- حساب GitHub (مجاني) لتفعيل GitHub Actions

### خطوات التثبيت

```bash
# 1. استخرج المشروع
unzip "UX-Ghost ZeroBaran.zip"
cd "UX-Ghost ZeroBaran"

# 2. شغّل المثبّت
bash install.sh

# 3. حرّر ملف .env واملأ المفاتيح
nano .env

# 4. ارفع مخطط قاعدة البيانات إلى Supabase
#    (لوحة تحكم Supabase → SQL Editor → ألصق محتوى supabase/schema.sql + supabase/rls/policies.sql)

# 5. أضف السكريبت إلى موقعك (انظر tracker/installation-example.html)
#    - ضع ملف ux-ghost-tracker.js على خادمك
#    - أضف التهيئة قبل إغلاق </body>
```

### تشغيل لوحة التحكم

```bash
source .venv/bin/activate
streamlit run dashboard/app.py
```

ثم افتح المتصفح على `http://localhost:8501`.

### تشغيل بوت تليجرام (اختياري — تفاعلي)

```bash
python telegram_bot/bot.py --mode poll
```

### تفعيل الجداول المجدولة على GitHub

1. ارفع المشروع إلى مستودع GitHub (يفضّل خاص).
2. في إعدادات المستودع → **Settings → Secrets and variables → Actions**.
3. أضف الأسرار التالية:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_KEY`
   - `GEMINI_API_KEY`
   - `GROQ_API_KEY` (اختياري)
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. (اختياري) في **Variables** أضف:
   - `UXG_AI_PROVIDER` = `gemini` (أو `groq`)
   - `UXG_RAGE_THRESHOLD` = `5`
   - `UXG_RAGE_VISITOR_MIN` = `3`
5. سيعمل `daily-analysis.yml` كل يوم 09:00 UTC، و`realtime-detector.yml` كل 30 دقيقة تلقائياً.

## 🔒 الامتثال للخصوصية (GDPR Compliant)

- **لا كوكيز تتبع دائمة**: السكريبت يستخدم `localStorage` و`sessionStorage` فقط لتعريف جلسة مجهولة (لا PII).
- **لا طرف ثالث**: البيانات تذهب مباشرة إلى Supabase الخاصة بك. لا يتم بيعها أو مشاركتها.
- **RLS صارمة**: مفتاح `anon` (الذي يستخدمه الموقع) يملك صلاحية INSERT فقط. لا أحد من خارج خادمك يستطيع قراءة الأحداث الخام.
- **حذف سهل**: للحذف الكامل لزائر معيّن، نفّذ:
  ```sql
  delete from uxg_visitors where visitor_id = 'v_xxx';
  -- cascade سيمسح كل أحداثه تلقائياً
  ```

لمزيد من التفاصيل، انظر [`docs/PRIVACY.md`](docs/PRIVACY.md).
